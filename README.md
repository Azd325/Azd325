## At work

The code is private, so this part is my own account. I carried out every Django major upgrade from 1.9 to 6.0, and I made AI-assisted development the team's standard.

## Right now

I'm making coding agents safe to trust in real repositories.
That means CLIs that are read-only until you confirm, skills that ask for proof before a PR, and fixes upstream in the agent tools I use every day.
